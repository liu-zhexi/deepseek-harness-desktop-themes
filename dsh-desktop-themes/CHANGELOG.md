# Changelog

## 1.0.0 — 2026-02-15

首个可安装版本。

### Added

- 三套内置主题：Tokyo Night、Catppuccin Mocha、黑金（统一 `--dsw-alias-*` token 派生）。
- 字体系统：界面/代码/中文字体、字号、行高、字重、连字、平滑、一键恢复默认。
- 半透明背景：窗口/侧边栏/内容面板/输入区透明度，0.55 对比度下限，恢复推荐值。
- 自定义壁纸：PNG/JPG/JPEG/WebP 校验、五种填充模式、位置/缩放/透明度/模糊/遮罩/饱和度/亮度。
- 毛玻璃：`backdrop-filter` + 降级、模糊/饱和度/面板透明度/边框高光/阴影、性能档位。
- 动画与性能：动画开关、一键低性能模式。
- 导入/导出 JSON（schema 校验 + 版本迁移）。
- 重置：分组默认值 / 全部默认值 / 清除壁纸。
- 设置页：分组导航、实时预览、无障碍键盘/焦点/双语。
- 宿主侧设置命名空间 `ui-desktop-themes`（schemastery schema）。
- 50 个单元测试 + 类型检查 + 构建脚本 + 性能微基准。
